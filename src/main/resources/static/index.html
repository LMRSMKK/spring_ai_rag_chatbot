飞书请假申请的完整流程如下：

第一步：登录飞书审批
打开飞书 App → 点击「工作台」→ 搜索「审批」→ 进入审批中心。

第二步：发起请假申请
点击「发起审批」→ 选择「请假申请」→ 填写以下信息：

  • 请假类型（年假 / 事假 / 病假 / 调休）
  • 起止时间（精确到小时）
  • 请假事由（必填，建议简洁说明）

第三步：提交审批
确认信息无误后点击「提交」，系统会自动转发给直属上级审批。

注意事项：

  • 请假 3 天以内：直属上级审批即可
  • 请假 3~7 天：需部门负责人审批
  • 请假 7 天以上：还需 HR 备案
  • 建议至少提前 1 个工作日 提交申请

如果是病假需要提供什么证明吗？
🧠
AI 助手 · DeepSeek V3
是的，病假需要提供证明材料：

1天内（含）：口头告知直属上级即可，事后补提交

超过1天：需提供以下任一证明：
• 医院出具的病假证明或诊断证明
• 挂号单 / 缴费凭证（需显示就诊日期）
• 药品处方单（需有医生签名）

证明需要在请假系统中上传附件，审批通过后由 HR 归档保存。急诊可先用电话报备，复工后 3 个工作日内补充材料。
